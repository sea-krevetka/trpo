# Лабораторная работа по тестированию CBLAS Level 3

## Описание работы

Интерфейсные тесты для библиотеки линейной алгебры OpenBLAS (CBLAS Level 3). Тестируются функции: gemm, symm, syrk, syr2k, trmm, trsm для всех типов данных (float, double, complex) в однопоточном и многопоточном режимах.

## Структура проекта

```

trpo/

├── OpenBLAS/              # Собранная библиотека OpenBLAS

├── cblas.h                # Заголовочный файл CBLAS

├── fake_cblas.c           # Библиотека с намеренными ошибками

├── test_cblas_level3.c    # Интерфейсные тесты

├── Makefile               # Файл сборки

└── README.md              # Инструкция по запуску

```

## Порядок запуска
### 1. Подготовка OpenBLAS

```bash

# Сборка OpenBLAS:

cd OpenBLAS
make -j4
cd ..
```

### 2. Сборка проекта

```bash
# Очистка предыдущей сборки
make clean
# Сборка всех тестов
make all
```

### 3. Запуск тестов с OpenBLAS

```bash
# Запуск тестов
make run_openblas

```
  

### 4. Запуск тестов с фейковой библиотекой

```bash
make run_fake

```

  

## Тестируемые функции

  

| Функция | Описание | Типы данных |

|---------|----------|-------------|

| `cblas_?gemm` | Общее матричное умножение | s, d, c, z |

| `cblas_?symm` | Симметричное умножение | s, d |

| `cblas_?syrk` | Симметрический ранг-k обновление | s, d |

| `cblas_?syr2k` | Симметрический ранг-2k обновление | s, d |

| `cblas_?trmm` | Треугольное умножение | s, d |

| `cblas_?trsm` | Решение треугольной системы | s, d |
